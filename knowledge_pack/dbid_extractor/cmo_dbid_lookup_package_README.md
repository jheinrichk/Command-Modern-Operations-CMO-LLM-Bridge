# CMO DBID Lookup Extraction Package

Included files:
- `cmo_sqlite_extraction_guide.md`
- `cmo_sql_extraction_queries.sql`
- `build_cmo_dbid_lookups.py`

This package does not contain extracted DBID lookup files yet because no SQLite DB was uploaded in the chat.

Run the Python script against your actual CMO `.db3` SQLite file to generate:
- `cmo_database_schema_reference.md`
- `cmo_dbid_lookup_platforms.lua`
- `cmo_dbid_lookup_facilities.lua`
- `cmo_loadout_lookup.lua`
and related CSV and summary files.
